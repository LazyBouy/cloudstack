# CloudStack from the Ground Up

A course for anyone who knows basic Linux and wants to understand Apache CloudStack: what it is, how it works, and why it's built the way it is, with the code as the source of truth.

Each module answers one question. Module 01 gives you the whole picture, and ends with a small cloud of your own to look at. Every module after it goes deep into one part.

| Module | The question it answers |
|---|---|
| [01 · General](01.General/README.md) | What is CloudStack, and what happens when someone asks it for a VM? |
| 02 · Management Server *(coming soon)* | What's inside the one program that runs the whole cloud? |
| 03 · Accounts and API *(coming soon)* | Who may ask the cloud for what, and how do they prove who they are? |
| 04 · Hosts and Hypervisors *(coming soon)* | How does CloudStack command a server it doesn't run on? |
| 05 · Storage *(coming soon)* | Where do a VM's disks and images live, and how do they move? |
| 06 · Networking *(coming soon)* | How does each VM get a network, and how are the cloud's customers kept apart? |
| 07 · Instances *(coming soon)* | How does CloudStack choose where a VM runs, and what happens over its life? |
| 08 · System VMs *(coming soon)* | How does CloudStack build, run and talk to its own VMs? |
| 09 · Operating a Cloud *(coming soon)* | How do you keep a cloud healthy, measured and up to date for years? |
| 10 · Extending CloudStack *(coming soon)* | How do you change CloudStack, add to it, and contribute back? |
| 11 · Beyond VMs *(optional, coming soon)* | What does CloudStack build out of VMs: Kubernetes clusters, autoscaling groups, backups? |

Go through them in order: each module builds on the ones before it.
