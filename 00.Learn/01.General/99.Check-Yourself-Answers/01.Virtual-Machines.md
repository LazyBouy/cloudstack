# Answers: What Is a Virtual Machine, and What Runs It?

[← Back to the post](../01.Virtual-Machines.md)

## 1. What does the VM have that the browser doesn't?

Its own operating system, kernel included, running on virtual hardware.

The browser is an ordinary process. It runs on your laptop's one kernel, and asks that kernel for CPU time, memory, files and the network.

The VM is a whole computer: virtual hardware, a guest operating system with its own kernel, and its own programs, which ask the VM's own kernel.

Yes, on a KVM host the VM shows up as one process. One of CloudStack's own scripts finds VMs exactly that way (see the Evidence below).

But that one process holds a computer. One process on the outside, a whole computer on the inside: that's why a VM isn't *just* a process.

A container sits in between. Like a VM, it keeps its application apart from the others; like the browser, it shares the machine's one kernel.

## 2. What does a hypervisor do, and where does it run?

It does two jobs. It shares out a computer's real CPU, memory and devices among the VMs, and it keeps the VMs apart.

It runs on the computer whose hardware it shares out. A hypervisor can't share out hardware it doesn't run on, so every host has its own.

On a KVM host, the hypervisor's core is part of the host's own Linux kernel, as loadable modules: `kvm`, plus `kvm_intel` or `kvm_amd` for the processor. That's why `lsmod | grep kvm` finds it. CloudStack's own KVM code names the same modules when a machine can't run VMs (see the Evidence below).

## 3. "A cloud of ten hosts runs one hypervisor": true or false?

False. A hypervisor shares out the hardware of the machine it runs on, so every host needs its own. CloudStack's docs say "Each host has hypervisor software installed on it", and CloudStack records each host's own hypervisor, and its version, in that host's record.

The correct sentence: a cloud of ten hosts runs ten hypervisors, one on each host.

They don't even have to be of the same kind. In the docs' words, "A single cloud can contain multiple hypervisor implementations" ([Concepts and Terminology](https://docs.cloudstack.apache.org/en/4.22.1.1/conceptsandterminology/concepts.html)).

This is the same mistake as the sentence "a group of hosts runs one hypervisor". Whatever the group, each host in it runs its own.

## 4. Why does the picture say *virtual* brand?

A virtual brand looks like a restaurant of its own: it has a name, a menu and recipes. But it has no kitchen of its own. Its meals are cooked at a station in a shared kitchen, next to other brands, each kept apart from the others.

A VM is the same. It looks like a computer of its own, but it runs on a share of a real host's hardware.

NIST's glossary has a second definition of a VM that says exactly this: "A virtual data processing system that appears to be at the disposal of a particular user but whose functions are accomplished by sharing the resources of a real data processing system" ([NIST](https://csrc.nist.gov/glossary/term/virtual_machine)).

In both, "virtual" means: it behaves like something of your own, but it's made by sharing something real.

### On KVM, a running VM is one process on its host

QEMU is one of the programs that work with KVM on a CloudStack host; [How Does a Hypervisor Work?](../02.Hypervisors.md#qemu-plays-each-vms-hardware) explains its job.

Every host's record has a field for the kind of hypervisor that host runs, and it can't be empty ([HostVO.java, lines 131–133](https://github.com/apache/cloudstack/blob/1a48a87587c03472feefb081cfac71b2ebd0f407/engine/schema/src/main/java/com/cloud/host/HostVO.java#L131-L133)):

```java
// cloudstack: plugins/hypervisors/kvm/src/main/java/com/cloud/hypervisor/kvm/resource/LibvirtComputingResource.java, lines 1419–1425
if (HypervisorType.KVM == hypervisorType) {
    /* Does node support HVM guest? If not, exit */
    if (!IsHVMEnabled(conn)) {
        throw new ConfigurationException("NO HVM support on this machine, please make sure: " + "1. VT/SVM is supported by your CPU, or is enabled in BIOS. "
                + "2. kvm modules are loaded (kvm, kvm_amd|kvm_intel)");
    }
}
```

The message says "this machine": the check runs on each host, for that host.
